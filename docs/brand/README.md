# سِيرة — ملفات الهوية

كل ملفات SVG متجهية، والنص محوّل إلى مسارات (لا تعتمد على وجود خط عربي في جهاز المستخدم
ولا في مولّدات الصور). النسخ PNG مُصدَّرة من ملفات SVG نفسها.

| الملف                          | الاستخدام                                                              |
| ------------------------------ | ---------------------------------------------------------------------- |
| `seera-logo.{svg,png}`         | الشعار الكامل (العلامة + «سِيرة» + `SEERA`) على خلفية فاتحة            |
| `seera-logo-white.{svg,png}`   | الشعار الكامل بالأبيض — للخلفيات الداكنة                               |
| `seera-logo-on-blue.{svg,png}` | الشعار الكامل داخل مستطيل أزرق — للعروض والمشاركات                     |
| `seera-mark.{svg,png}`         | العلامة وحدها (بلا كلمة) على خلفية فاتحة                               |
| `seera-mark-white.svg`         | العلامة وحدها بالأبيض — للوضع الليلي                                   |
| `seera-app-icon.{svg,png}`     | مربّع أزرق بزوايا دائرية مع العلامة بيضاء — أيقونة التطبيق والـfavicon |

## الألوان

| الدور                         | اللون     |

| الكلمة ونقطة العلامة (فاتح)   | `#0F1530` |
| سطر `SEERA` (فاتح)            | `#4B5368` |
| العلامة والكلمة (داكن)        | `#FFFFFF` |

## الاستخدام في التطبيق

- **الشعار والعلامة:** [`src/components/shared/logo.tsx`](../../src/components/shared/logo.tsx) —
  يصدّر وسمَي `<img>` (فاتح وداكن) ويخفي أحدهما بـ`dark:hidden` / `hidden dark:block`، فلا وميض
  عند أول رسم ولا اختلاف في التصيير. الشعار واحد للّغتين (يحمل الكتابتين)، فلا يتبدّل مع اللغة.
- **الـfavicon:** `src/app/icon.svg` نسخة من `seera-app-icon.svg`.
- **أيقونة iOS:** `src/app/apple-icon.png` مُصدَّرة من `seera-app-icon.png` إلى 180×180 بـ`sharp`.
- **صورة المشاركة:** [`src/app/opengraph-image.tsx`](../../src/app/opengraph-image.tsx) يضمّن مسار
  العلامة كـJSX، لأن `next/og` لا يقرأ ملفات SVG خارجية.
- **البريد:** `EMAIL_THEME.primary` في [`src/lib/constants/mail.ts`](../../src/lib/constants/mail.ts)
  يحمل `#2E31E6` نفسه.

## قواعد الاستخدام

- أقل ارتفاع للشعار الكامل: 24px. تحته استخدم العلامة وحدها.
- المسافة الآمنة حول الشعار: ارتفاع العلامة ÷ 2.
- لا تلوّنه بغير `#2E31E6` أو الأبيض.
- لا تمدّه ولا تدره ولا تضف له ظلًا.
- المصدر القابل للتحرير: لوحة التصميم «شعار سِيرة» (Design canvas).
